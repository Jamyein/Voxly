# 艺术家分隔符功能设计文档

## 概述

为艺术家 Tab 添加艺术家分隔符功能，当艺术家字段包含 `&` 或 `\` 时进行分割，使艺术家页面内的艺术家能够正确分类。用户可在设置页面自定义分隔符。

## 背景

当前艺术家聚合逻辑直接使用完整的艺术家名称作为 key，导致：
- 艺术家字段为 "A & B" 时，只会显示为一个艺术家 "A & B"
- 用户无法通过首字母索引快速找到 "A" 或 "B" 艺术家

## 设计方案

### 1. 数据层改动

#### SettingsDataStore.kt

新增两个设置项：

| 设置项 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `ARTIST_SEPARATOR_ENABLED` | Boolean | true | 是否启用艺术家分隔功能 |
| `ARTIST_SEPARATORS` | String | "&\/" | 分隔符字符串 |

### 2. 业务逻辑改动

#### FileBrowserViewModel.kt

修改 `aggregateData()` 函数中的艺术家聚合逻辑：

```
示例 1：艺术家字段 = "A & B"
分隔符 = ["&", "\"]

分割结果：A、B
歌曲会在 A 和 B 两个艺术家下都显示

示例 2：艺术家字段 = "A \ B \ C"
分隔符 = ["&", "\"]

分割结果：A、B、C
歌曲会在 A、B、C 三个艺术家下都显示
```

具体逻辑：
1. 读取分隔符设置
2. 对每个音频文件的 `artist` 字段进行分割
3. 遇到 `&` 或 `\` 任一字符即分割
4. 分割后的每个艺术家名称都会创建一个分组
5. 原始歌曲会出现在所有分割后的艺术家下

### 3. UI 层改动

#### SettingsScreen.kt

在设置页面添加新设置区块：

- **开关行**：启用艺术家分隔
  - 标题："启用艺术家分隔"
  - 副标题："将多艺术家字段分割显示"
- **文本输入行**（当启用时显示）：
  - 标题："分隔符"
  - 副标题："用于分割艺术家字段的字符，默认 & \"

### 4. 边界情况处理

- 空艺术家字段：跳过分割逻辑
- 仅有一个分割后的艺术家：正常显示
- 分割后产生空字符串：过滤掉
- 自定义分隔符为空：使用默认分隔符

## 依赖关系

```
SettingsDataStore (新增设置项)
    ↓
FileBrowserViewModel (读取设置并应用)
    ↓
SettingsScreen (UI 控制)
```

## 测试用例

1. 艺术家字段 "A & B"，分隔符 "&\"，应显示 A、B 两个艺术家
2. 艺术家字段 "A \ B"，分隔符 "&\"，应显示 A、B 两个艺术家
3. 艺术家字段 "A & B \ C"，分隔符 "&\"，应显示 A、B、C 三个艺术家
4. 关闭分隔符开关，艺术家字段 "A & B" 应显示为 "A & B"（不分割）
5. 自定义分隔符 ","，艺术家字段 "A,B"，应显示 A、B 两个艺术家
