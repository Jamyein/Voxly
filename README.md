# Voxly - MP3 Tag Editor for Android

A modern Android MP3 tag editor with online metadata search, built with Kotlin + Jetpack Compose.

## Features

- Edit ID3 tags: title, artist, album, genre, year, track number
- Album art: view, replace, remove
- Multi-format: MP3, FLAC, OGG, M4A, WMA, WAV, APE
- ReplayGain scanning
- **5 online sources**: MusicBrainz, Apple Music, NetEase, Tencent, LRCLib

## Tech Stack

Kotlin | Jetpack Compose | Material Design 3 | MVVM + Clean Architecture | Hilt | jaudiotagger

## Build

```bash
./gradlew build
```

## Permissions

`READ_MEDIA_AUDIO` | `WRITE_EXTERNAL_STORAGE` | `INTERNET`

# Voxly - 安卓音乐标签编辑器

- **5 个在线数据源**：MusicBrainz、Apple Music、网易云、腾讯、LRCLib
